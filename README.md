# FlexiGo Travel

Premium pre-scheduled private transfer service landing page built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Local Development

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Quality Checks

```bash
npm run lint
npm run build
```

git remote add origin <YOUR_GITHUB_REPO_URL>
